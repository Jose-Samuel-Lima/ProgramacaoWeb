# 💻 Programação Web

Repositório destinado ao armazenamento e desenvolvimento das atividades, exercícios, trabalhos e projetos realizados durante a disciplina de **Programação Web**.

## 📚 Sobre o Projeto

Este repositório reúne os conteúdos e práticas desenvolvidos ao longo da disciplina, com o objetivo de aplicar conceitos de desenvolvimento web na construção de páginas, sistemas e aplicações.

Durante o desenvolvimento das atividades, serão abordados conceitos relacionados a:

* Estruturação de páginas web;
* HTML;
* CSS;
* JavaScript;
* Desenvolvimento de interfaces;
* Interação com o usuário;
* Responsividade;
* Manipulação do DOM;
* Consumo de APIs;
* Desenvolvimento de aplicações web.

## 🛠️ Tecnologias

As principais tecnologias utilizadas no desenvolvimento das atividades são:

* **HTML5** — estrutura das páginas;
* **CSS3** — estilização e layout;
* **JavaScript** — lógica e interatividade;
* **Git** — controle de versão;
* **GitHub** — armazenamento e gerenciamento do repositório.

> Outras tecnologias poderão ser adicionadas conforme o avanço da disciplina e dos projetos.

## 🎯 Objetivos

O principal objetivo deste repositório é registrar a evolução do aprendizado na disciplina de Programação Web, permitindo acompanhar a implementação prática dos conteúdos estudados.

Entre os objetivos estão:

1. Desenvolver páginas web utilizando HTML e CSS;
2. Criar funcionalidades utilizando JavaScript;
3. Aplicar conceitos de desenvolvimento web na prática;
4. Desenvolver interfaces organizadas e responsivas;
5. Utilizar controle de versão com Git e GitHub;
6. Desenvolver projetos web de forma progressiva.

## 🚀 Como Executar

Para executar as atividades localmente:

1. Clone este repositório:

```bash
git clone https://github.com/Jose-Samuel-Lima/ProgramacaoWeb
```

2. Acesse a pasta:

```bash
cd Programacao-Web
```

3. Escolha a atividade ou projeto desejado.

4. Abra o arquivo `index.html` em um navegador.

Para facilitar o desenvolvimento, também pode ser utilizado o **Visual Studio Code** com a extensão **Live Server**.

## 📈 Desenvolvimento

O repositório será atualizado durante o decorrer da disciplina, recebendo novas atividades, exercícios e projetos.

Cada atividade será organizada de forma independente para facilitar a compreensão, manutenção e execução dos códigos.
